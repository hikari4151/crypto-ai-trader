## 2. 还没试的方向（按独立维度 × 可行性排序）

### 2.1 期权偏斜（skew / 尾部风险定价）—— 独立维度，可行性中
- **为什么值得**：DVOL 测的是波动率**水平**；skew（25d put-call IV 差）测的是**尾部风险定价**，是正交的风险溢价维度（崩盘保护贵 = 市场恐惧）。行为金融里最经典的风险溢价来源之一。
- **成本/风险**：Deribit 免费渠道的历史 skew 有限（逐合约拉 ticker 只留近期）→ 样本可能不足 1 年；需要期权链解析代码。
- **判定**：四关 + 时间外推 + 交易级；预期命中率中等。

### 2.2 更高频（5m 长历史）—— 同维度补样本，可行性高
- **为什么值得**：P3 的 5m 结论建立在 **32 天样本**（9351 根）上——**样本不足的否定不可信**。拉 2 年 5m（~21 万根/标的）重测，是"补完已知缺陷"而非新维度。
- **成本/风险**：Binance 5m 历史可翻页拉（2024-01 起已验证第一页）；5m 换手高 → 5x 成本门槛更严。
- **判定**：同 P3 协议但用 2 年样本 + 四关；预期：技术指标 5m 大概率仍不成立，但**能给出可信的最终结论**（把"样本不足"变成"确实没有"）。

### 2.3 跨交易所价差套利 —— 结构性收益，可行性低-中
- **为什么值得**：Binance vs OKX 同合约价差是价格结构维度；做 delta 中性的"贵所卖/便宜所买"赚价差收敛。
- **成本/风险**：需要双所同时下单（工程复杂）；价差大概率已被套利资金抹平（与费率套利同命运，P22 教训）；需要两所 API key。
- **判定**：先拉历史价差序列看是否还有统计显著偏离 + 能否覆盖往返成本；预期：低。

### 2.4 做市 / 订单簿微观结构 —— 结构性收益，可行性低（需实盘）
- **为什么值得**：吃价差是少数**不依赖预测方向**的结构性收益；低延迟策略有真实壁垒。
- **成本/风险**：回测无法验证（订单簿动态需真实撮合）→ 只能实盘最小挂单实验；需要 OKX 订单簿流 + 低延迟基础设施；可能亏损（库存风险）。
- **判定**：OKX 实盘链路已验证可用，可做最小做市演练（窄幅双向挂单，观察成交率/价差收益）；但**需要你明确授权真钱实验**。
- **预期**：唯一可能还有真实壁垒的方向，但也是成本/风险最高的。

### 2.5 链上实体净流（交易所净流入/流出）—— 独立维度，可行性低
- **为什么值得**：与"活跃地址/交易数"（已测）不同，**实体净流**反映聪明钱移动，是更深的行为信号。
- **成本/风险**：免费渠道（blockchain.com）无此数据；Glassnode/CryptoQuant 需付费 API。
- **判定**：除非你愿意提供付费 key，否则跳过。

## 3. 我的推荐（按投入产出）

| 优先级 | 方向 | 理由 |
|---|---|---|
| **1（推荐）** | **5m 长历史重测** | 唯一"补完已测方向的样本缺陷"的低风险工作；几小时可完成；给出可信终局结论 |
| **2** | **期权 skew** | 唯一剩余的正交免费维度；但历史样本可能不足，先探测再决定 |
| **3** | 跨所价差 | 可快速拉历史价差做前置检查（不值得就停） |
| **4** | 做市 | 真 alpha 概率最高的方向，但需要真钱 + 授权，另起专项 |

**执行顺序建议**：先做 1（5m 长历史，网络通即可跑）→ 同时探测 2（skew 历史可得性）→ 3 的前置检查（价差统计）→ 4 需要你拍板。

## 4. 判定标准（不变，防再犯）

任何候选信号必须过**全部**：
1. 质量门：OOS 后 30% |rank_ic|≥0.03、|icir|≥0.1、换手≤0.5
2. 分年同号：≥3~4 年方向一致
3. **时间外推**：IS 与 OOS 同号且 |OOS|≥0.03（P27 固化）
4. 跨品种/5 折：多标的同号、5 折外推方向稳
5. **交易级**：1x/5x 成本后净收益仍为正（P30 固化）

工具已就绪：`.optim/p30_voldiv_check.py`（严格复核）+ `.optim/p31_llm_loop_v2.py`（假设闭环）。

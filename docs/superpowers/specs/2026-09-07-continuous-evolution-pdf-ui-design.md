# 持续进化页 PDF 设计稿 UI 改造规格

## 目标

按照用户提供的《持续进化 · UI 设计稿.pdf》改造持续进化页主内容区。设计稿已经包含功能展示映射，因此实现以视觉稿为唯一页面结构依据，不额外引入新的产品功能或交互模型。

侧边栏不属于本次改造范围，必须保持现状。

## 约束

- 保留现有持续进化 API、轮询、状态对象、配置保存、训练触发、版本查看、版本回退、锚点重置和手动 DRL 实验台逻辑。
- 保留现有 Vue 响应式字段和方法名称，优先只改 `web/static/index.html` 的持续进化模板和局部样式。
- 不改变其他页面、全局导航或后端接口。
- 设计稿中展示的文案、布局关系、状态色和组件层级优先于当前页面结构。

## 页面结构

### 主页面

- 顶部标题区：持续进化标题、副标题、导出进化日志、刷新状态。
- 顶部单行状态条：运行状态、标的池、因子挖掘、策略 DRL、下一次训练，以及暂停、禁用、立即训练等高频操作。
- 内容区使用左右两栏：
  - 左侧主栏：训练轮次曲线、模型状态横向卡片组。
  - 右侧操作栏：训练配置、回退基线告警、手动触发训练。
- 页面底部：手动 DRL 实验台，默认展示设计稿中的紧凑控制和训练进度区域，同时保留现有折叠与四种实验模式。

### 训练轮次曲线

- 作为左栏首个主要面板。
- 保留因子挖掘、策略 DRL、元策略三种模型切换。
- 保留接受轮次、拦截/回退轮次、最佳 fitness、接受率等信息。
- 曲线容器和状态图例使用设计稿的深色面板、蓝色主线、红色异常点和绿色最佳值。

### 模型状态

- 三个模型以横向卡片并排展示：因子挖掘、策略 DRL、元策略控制器。
- 卡片统一展示模型名、PPO 标签、fitness、标的、训练轮次、上次训练、候选/部署摘要和查看版本。
- 异常模型使用橙色边框和橙色状态提示单独标识。
- 保留各模型当前已有的差异字段：候选/部署、跨标 OOS、锚点不一致、子策略、下次训练、错误和 OOS 拒绝。

### 训练配置

- 放在右栏顶部。
- 以设计稿中的紧凑下拉字段展示训练标的池和训练时间周期。
- 保留可热更新和保存配置能力。
- 不在该区域堆叠自动训练高级超参；高级参数继续由下方手动 DRL 实验台承载。

### 回退基线

- 放在右栏中部，作为常驻告警卡，而非主栏内嵌提示。
- 复用 `evolveAnchorIssues`、`evolveAnchorLocked` 和 `resetEvolveAnchor`。
- 每个异常展示状态标签、模型、fitness、未接受轮次、原因和可用的重置锚点操作。
- 无告警时不渲染该卡片，避免空占位。

### 手动触发训练

- 放在右栏底部，纵向排列因子挖掘、策略训练、元策略训练按钮。
- 保留现有运行中、禁用、忙碌和训练中状态。
- 按设计稿使用蓝色、紫色等动作色，但状态信息只通过现有语义色表达。

### 手动 DRL 实验台

- 保留页面底部独立窗口和折叠开关。
- 以紧凑参数网格展示训练轮数、K 线数量、奖励/惩罚参数、学习率、折扣因子和起始资金等已有字段。
- 保留 GPU 加速、续训模型、早停保护、强制自动训练、开始训练、刷新模型库、训练进度和结果/OOS 反馈。
- 保留 RL 因子挖掘、自适应策略训练、已训练模型库、跨行情 OOS 四种模式，不删除任何已有内容。

### 版本弹层

- 保持独立遮罩弹层，避免打开版本列表造成页面高度跳动。
- 按设计稿展示版本、fitness、训练时间和操作。
- 最佳版本使用绿色高亮；当前版本显示当前版本状态；其余版本保留回退按钮。
- 保留无版本空态和回退后热加载/审计行为。

## 视觉规范

- 延续现有深色 macOS 风格和 CSS 变量体系。
- 页面主操作使用 `#0A84FF` / `var(--accent)`，成功使用绿色，警告使用橙色，危险使用红色。
- 面板保持低对比深色背景、细边框、轻微圆角；不为持续进化页引入渐变、阴影堆叠或新的侧边栏样式。
- 通过层级、间距、边框和状态色表达信息，不使用额外装饰插图。
- 保持桌面双栏布局，在窄屏下堆叠为单栏，确保状态、按钮和模型卡不发生横向溢出。

## 验证

- 静态检查持续进化模板中现有响应式字段和方法仍全部有引用。
- 运行现有相关测试，至少覆盖持续进化状态、轮次、族群/OOS、锚点和版本回退相关测试。
- 启动 Web 页面进行浏览器级检查：桌面宽屏、窄屏、无数据、训练中、锚点告警、版本弹层和 DRL 实验台展开态。
- 确认侧边栏及其他视图无 DOM 或样式回归。

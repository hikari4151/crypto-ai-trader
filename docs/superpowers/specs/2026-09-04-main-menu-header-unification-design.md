# 主菜单页头与顶栏统一设计

## 背景

当前主菜单页面大多已经使用 `.page-head` 与 `.page-title`，但历史回测和历史战绩仍存在独立布局或重复样式。顶部菜单栏与上下文栏虽然已有相同的玻璃材质覆盖，两个栏之间仍保留视觉分割边界，整体感不一致。

## 目标

1. 让所有主菜单页面采用与仪表盘一致的页头结构和标题层级。
2. 让顶部菜单栏与上下文栏看起来像一个连续的玻璃顶栏，同时保留两栏的功能、固定位置和高度。
3. 保持主菜单信息架构、交互行为、响应式空间预留和设置页内部标题不变。

## 非目标

- 不重构为独立 Vue 组件或拆分 `index.html`。
- 不改 settings 页面内部的风控、通知、AI 服务等分区标题。
- 不改变菜单按钮、上下文状态、轮询、路由和业务逻辑。
- 不调整顶栏高度：菜单栏保持 46px，上下文栏保持 44px，页面顶部预留保持 90px。

## 设计方案

### 主菜单页头

保留现有公共 `.page-head`、`.page-title`、`.page-subtitle` 样式作为唯一来源。主菜单页面统一采用仪表盘的 DOM 形态：

- 外层使用 `.page-head`。
- 标题使用 `h1.page-title`，保留现有页面图标和文案。
- 副标题使用 `.page-subtitle`。
- 删除主标题上的重复 inline margin。
- 历史回测从独立 flex 标题布局迁移到 `.page-head`。
- 历史战绩移除重复的 `.perf-head` 页头样式，仅保留真正必要的页面特有规则。

仅调整主视图：仪表盘、AI 与 API、AI 策略工坊、全部策略、历史回测、量化研究、持续进化、历史战绩、实盘启动。

### 连续玻璃顶栏

保留 `.menubar` 与 `.ctxbar` 两个 DOM 层和现有功能。统一最终视觉规则：

- 两者使用相同的背景混合、模糊、饱和度和主题适配。
- 移除两栏相邻边缘的白色分割线和重复阴影，避免中间出现横向白线。
- 仅保留整体底部的弱边界，菜单栏与上下文栏内部不再形成独立分隔。
- 保留菜单栏顶部内阴影与上下文栏底部整体阴影所需的层次感，但不让其成为中间分割线。
- 保持 `z-index`、fixed 定位、`top: 46px` 和 `body.pt-[90px]` 不变。

## 实施与验证

修改范围限于 `web/static/index.html`。验证包括：

- `python scripts/check_js.py web/static/index.html`
- 现有 UI guard 检查脚本（如适用）
- 通过静态检索确认主菜单页头均使用 `.page-head`，且没有重新引入 setup 中以下划线开头的模板绑定。
- 运行相关 pytest，确认本次只涉及模板/CSS，不改变后端行为。
- 通过浏览器或现有本地页面进行桌面与窄屏检查：标题不重叠，顶栏中间无白色分割线，90px 顶部内容预留正确。
